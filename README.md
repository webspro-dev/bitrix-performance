# Bitrix Performance Toolkit

Инструмент для диагностики и базовой оптимизации производительности проекта на 1С-Битрикс: Управление сайтом.

## Возможности

- административная страница диагностики;
- проверка версии PHP и доступных расширений;
- проверка конфигурации PHP: memory limit, max execution time, OPcache;
- проверка доступности MySQL и времени простого запроса;
- проверка наличия и доступности каталогов кеша и журналов;
- сбор безопасной сводки по окружению без раскрытия паролей и токенов;
- очистка кеша через штатный API Битрикс с подтверждением;
- очистка managed cache через штатный API Битрикс с подтверждением;
- логирование действий администратора;
- настройки модуля;
- установка и удаление модуля через стандартный механизм Bitrix;
- адаптивная административная страница.

Модуль не изменяет ядро Битрикс и не выполняет автоматические изменения конфигурации сервера. Диагностика показывает рекомендации, а очистка кеша выполняется только по явному действию администратора.

## Требования

- 1С-Битрикс: Управление сайтом;
- PHP 8.1 или новее;
- MySQL/MariaDB;
- административный доступ к сайту;
- права на запись в `/bitrix/cache` и `/bitrix/managed_cache` для очистки кеша.

## Установка на существующий сайт

### 1. Загрузите файлы

Скопируйте каталог `local/modules/stadigit.performance` в корень сайта:

```text
/var/www/site/local/modules/stadigit.performance/
```

Если каталога `local/modules` ещё нет, создайте его.

### 2. Установите модуль

1. Войдите в административную панель Bitrix.
2. Откройте **Настройки → Настройки продукта → Модули**.
3. Найдите модуль **Инструменты производительности Stadigit** (`stadigit.performance`).
4. Нажмите **Установить**.

Если модуль не появился в списке, проверьте права на каталог и соответствие пути `local/modules/stadigit.performance`.

### 3. Откройте диагностику

После установки откройте:

```text
/bitrix/admin/performance_dashboard.php
```

Или используйте пункт меню **Сервисы → Производительность сайта**.

### 4. Запустите проверки

На панели отображаются:
- статус проверок;
- сведения о PHP;
- состояние OPcache;
- время выполнения простого SQL-запроса;
- доступность каталогов кеша;
- рекомендации по найденным настройкам.

Для очистки кеша используйте соответствующие кнопки на странице. Действия требуют POST-запроса и проверки сессии администратора.

## Установка через Git

Рекомендуется сначала установить модуль на тестовом окружении и проверить его совместимость с версией вашего проекта.

```bash
cd /path/to/bitrix-site
mkdir -p local/modules
```

Скопируйте каталог модуля в `local/modules/stadigit.performance`, затем установите его в административной панели.

## Права доступа

- Доступ к административной странице имеет только пользователь с правами администратора.
- Очистка кеша выполняется только из административной сессии через POST.
- В журнал не записываются пароли, cookies или токены.
- Диагностика не выводит значения переменных окружения и параметры подключения к БД.

## Как устроено решение

- `Diagnostics` собирает информацию о PHP, OPcache, файловой системе и БД.
- `CacheManager` вызывает штатные API Битрикс для очистки кеша.
- `install/index.php` регистрирует модуль в стандартном менеджере модулей.
- `admin/performance_dashboard.php` отображает результаты проверок и обрабатывает действия администратора.
- `options.php` хранит настройки модуля через API настроек Битрикс.

## Проверка перед production

1. Сделайте резервную копию сайта и БД.
2. Установите модуль на staging-копии.
3. Убедитесь, что административная страница открывается.
4. Проверьте диагностику при включённом и выключенном OPcache.
5. Проверьте очистку кеша в период низкой нагрузки.
6. Проверьте журналы PHP и Bitrix после установки.

## Разработка

Основные классы находятся в `local/modules/stadigit.performance/lib/`.

Добавляя новые проверки, не выводите секреты конфигурации и не запускайте тяжёлые запросы без лимитов. Для долгих нагрузочных тестов используйте отдельное staging-окружение.
