# stadigit.performance

Модуль Bitrix для диагностики PHP, OPcache, соединения с БД и доступности кеш-каталогов.

## Установка

Скопируйте каталог в `local/modules/stadigit.performance`, затем установите модуль через административный раздел Bitrix → Настройки → Модули.

Административная страница: `/bitrix/admin/performance_dashboard.php`.

## Безопасность

Очистка кеша доступна только администраторам, выполняется POST-запросом и защищена сессионным токеном Bitrix. Диагностика не выводит секретные параметры подключения.
